How it works: This tool is a prompt construction assistant. It builds a carefully structured instruction for a general-purpose AI (Claude, ChatGPT, Gemini, Perplexity). The AI then performs the workforce analysis using its own tools and training. Always verify labor-market figures against primary sources: BLS OEWS, BLS Employment Projections, O*NET OnLine, CareerOneStop, and state-level LMI (in Illinois: IDES Workforce Info).
The Prompt
Awaiting Input Select a tab, enter one or more job titles or SOC occupation codes, configure geography and report sections, then press Build the Prompt. The generated instruction will appear here — ready to copy into any AI assistant.

This tool inverts the usual curriculum-planning question. Rather than asking “does demand exist for what we already teach?”, it asks: “what should we teach, given where the demand actually is?”
